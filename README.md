## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/acesonder/HOOKUP.git
cd HOOKUP
```

2. Install dependencies:
```bash
npm install
```

3. Start the server:
```bash
npm start
```

4. Open your browser and navigate to:
```
http://localhost:3000
```

## 📄 API Endpoints

### User Management
- `POST /api/register` - Register new user
- `GET /api/users/:id` - Get user profile

### Video Content
- `POST /api/videos/upload` - Upload video
- `GET /api/videos` - Get all videos
- `GET /api/videos/:id` - Get specific video

### Pictures
- `POST /api/pictures/upload` - Upload picture
- `GET /api/pictures` - Get all pictures
- `GET /api/pictures/:id` - Get specific picture

### Meetups
- `POST /api/meetups/create` - Create meetup
- `GET /api/meetups` - Get Ontario meetups
- `POST /api/meetups/:id/join` - Join meetup
